##  Overview

This project explores **Computational Knot Theory**, combining theoretical concepts from topology with algorithmic and programming-based approaches.  
We study knot representations, transformations, and invariants, and implement computational tools to manipulate and analyze knot words.

The project includes both **Python** and **C++** implementations for generating, verifying, transforming, and visualizing Lattice knots.


##  Topics Covered

### **1. Knot Theory Basics**
- Knot Definitions
- Knot diagrams and projections  
- Polygonal and lattice knots  

### **2. Reidemeister Moves**
- Type I, II, III moves  
- Use in simplifying knot diagrams  
- Computational role in knot equivalence  

### **4. Knot Words**
- Validity checks for knot words  
- Elementary switches and doubling operations  
- Studying transformations between knot words  

### **5. Fundamental Groups**
- Group-based invariants for distinguishing knots
